# قُرعة | Quraa
أداة عربية عامة لاختيار الفائزين عشوائيًا دون تكرار.

## التشغيل
افتح `index.html` في متصفح حديث. لا تحتاج إلى تثبيت أو قاعدة بيانات.
أدخل كل اسم في سطر، حدّد عدد الفائزين، واضغط بدء القرعة. كل ضغطة إيقاف تختار فائزًا جديدًا.
الأسماء والنتائج تبقى في المتصفح ولا تُرسل إلى خادم. يستعمل الاختيار crypto.getRandomValues.

## النشر على GitHub Pages
1. أنشئ مستودعًا عامًا باسم `quraa`.
2. ارفع index.html و .nojekyll و README.md إلى الفرع main.
3. من Settings ثم Pages اختر Deploy from a branch ثم main والمجلد / (root)، واضغط Save.
4. انتظر اكتمال النشر؛ يظهر رابط الموقع في صفحة Pages.

## الملفات
index.html يتضمن التصميم والشيفرة وكل ما يلزم للتشغيل، ولا يعتمد على مكتبات خارجية.
